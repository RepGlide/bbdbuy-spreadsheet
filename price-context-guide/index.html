Price Context Guide

Read a price with its currency, time, version, source, and the actual page — not as a bare number.

A number is not a price

A price only becomes meaningful when its context is attached. A bare number in a cell tells you almost nothing by itself.

Currency

The currency tells you what the number is denominated in. Without it, the number is unreadable. Always read the currency alongside the number.

Time

A price is a snapshot at a moment. It is not a live rate and may have changed since the row was written.

Version

Listings often split into versions or variants, each with its own price. Confirm which version the number belongs to.

Source

Where the number came from shapes how much weight to give it — a Sheet cell, a category page, or the target page itself.

Actual page

The destination page is where the price is finally confirmed. Re-check the number there before relying on it.
